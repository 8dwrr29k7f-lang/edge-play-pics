# Railway

## Start command (required)
```
sh start.sh
```

This unpacks `src.zip` with **Python** (Railway often has no `unzip` binary).

## Variables
```
DISCORD_TOKEN=
CLIENT_ID=
GUILD_ID=
PICS_CHANNEL_ID=
SCAN_MINUTES=15
TZ=America/Chicago
```

## Good logs
```
Unpacking src.zip into src/ (python)...
Launching node src/index.js
```
