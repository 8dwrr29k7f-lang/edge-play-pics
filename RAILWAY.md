# Railway

## Start command
```
sh start.sh
```

Unpacks `src.zip` with **Node adm-zip** (no system unzip/python required).

## Variables
```
DISCORD_TOKEN=
CLIENT_ID=
GUILD_ID=
PICS_CHANNEL_ID=
SCAN_MINUTES=15
TZ=America/Chicago
```

## Good logs
```
Unpacking src.zip into src/ (node adm-zip)...
Unpack OK
Launching node src/index.js
```
